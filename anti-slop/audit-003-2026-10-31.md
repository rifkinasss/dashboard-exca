# Audit antislop: header dan filter terpusat

Cakupan: penghapusan pemilih periode di header dan penataan label filter di sidebar. Tidak ada temuan pada perubahan dalam cakupan ini.

Header tetap menggunakan ilustrasi yang ada dan tidak meluap pada lebar 320, 390, 768, 1024, dan 1680 piksel. Sidebar terlihat pada desktop dan dapat dibuka pada layar yang lebih kecil. Dua input tanggal memakai state yang sama untuk KPI dan grafik; target meminta satu bulan penuh jika rentangnya tidak sesuai.

Pemeriksaan browser menggunakan data sintetis dan tidak mencakup audit seluruh dashboard.
